## Hey, I’m Jazz

I build useful software across **web, mobile, AI-assisted tools, and interactive experiences**—from full-stack products with real data flows to native Android apps and game prototypes. I care about clear interfaces, practical engineering, and documenting what a project actually does.

**Currently exploring:** AI agents · developer tools · workflow automation · product analytics · mobile-first UX
